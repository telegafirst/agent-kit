# Security Policy

## Reporting a vulnerability

Please report potential vulnerabilities privately through the GitHub Security Advisories flow for the `telegafirst/agent-kit` repository. Include a clear reproduction, affected versions, expected impact, and any proposed mitigation.

Do not disclose the issue in a public GitHub issue, pull request, discussion, skill, or documentation page before a fix is available.

## What to expect

Maintainers will acknowledge a valid report, assess its impact, coordinate a fix, and publish release notes when disclosure is safe. Reports should not include production credentials, customer data, or other sensitive material.
