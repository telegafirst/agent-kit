# Site launch checklist

- Confirm the owner chose the right jurisdiction zone for the domain.
- Keep the complete site bundle available before requesting uploads.
- Verify the public call to action leads to the intended TelegaFirst bot.
- Declare any form before publishing its page.
- Read the manifest after publishing and report the active host to the owner.
- Give the owner the links of every published page from **page_urls** (or `site_list_pages`), each with what it is for; an empty **page_urls** is not done until its recovery is followed.
- A closed section is closed by a password on the platform and a rule that names it, never by a script in the page; the owner has the password to hand to the audience.
