# Contributing to TelegaFirst agent-kit

Thank you for improving the TelegaFirst agent skills package.

## Pull requests

1. Keep each pull request focused on one user-facing improvement or correction.
2. Run the package validation and include the result in the pull request description.
3. Do not add secrets, API keys, or customer data to skills, examples, fixtures, or commits.
4. Describe agent-facing behavior changes in the pull request so maintainers can assign a permanent changelog identifier.

## Accepted contributions

When a pull request is accepted, the maintainer must add its author to `CHANGELOG.md` together with the relevant agent-facing change entry. A contribution is not fully accepted until that changelog attribution is present.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md) instead.
